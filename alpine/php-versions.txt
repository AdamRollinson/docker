# build.sh and .github/workflows/docker-build.yml read this file. The php image is
# compiled from the tarball, which must match the checksum and carry a valid signature
# from a php.net release manager, so a build fails instead of silently compiling a
# different PHP. Images are tagged with both the minor and the release (php:8.3 and
# php:8.3.36).
#
# Final releases come from www.php.net/distributions. Pre-releases come from the
# release manager's directory on downloads.php.net and keep Alpine's spelling here
# (8.6.0_rc4 for php.net's 8.6.0RC4); they are published on a channel tag (php:8.6-rc)
# plus the exact tag, and the bare minor tag (php:8.6) only appears once the final
# release is pinned. Check php.net for newer releases, and rewrite the lines with
# --update:
#   alpine/check-php-versions.sh
