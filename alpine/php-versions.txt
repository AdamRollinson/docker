# Pinned PHP releases, one per line: <minor> <release>
#
# build.sh and .github/workflows/docker-build.yml read this file. The release
# is passed to the Dockerfiles as PHP_PATCH_VERSION and enforced with an apk
# version constraint, so a build fails instead of silently installing a
# different PHP. Images are tagged with both values (php:8.3 and php:8.3.35).
#
# The release must exist in the Alpine repositories the Dockerfiles use: the base
# image's stable branch (main, community) plus edge main, community and testing
# (8.2 and pre-release 8.6 only exist in edge/testing). Pre-releases use Alpine's
# spelling, e.g. 8.6.0_rc3, and are published on a channel tag (php:8.6-rc) plus
# the exact tag; the bare minor tag (php:8.6) only appears once the final release
# is pinned. Check what is available with:
#   alpine/check-php-versions.sh
