# PECL extensions compiled into the images, one per line:
#   <image> <extension> <version or https:// URL> <sha256 of the archive> <minors, or *>
#
# image is php (built into the php image and everything on top of it) or dev (php-nginx-dev
# only). Lines are built in order, so igbinary and msgpack come before redis, which is
# compiled with both serialisers. A minor that no line lists simply does not get that extension
# (imagick has no PHP 8.6 support yet). igbinary, msgpack, apcu and redis on 8.6 are unreleased upstream
# commits with the PHP 8.6 build fixes, until releases carry them. The php image ships this file at
# /usr/local/etc/php/pecl-extensions.txt, which is where php-nginx-dev reads its xdebug line.
#
# alpine/check-php-versions.sh reports newer PECL releases and --update applies patch
# releases within the same major.minor; anything larger is a manual change.
