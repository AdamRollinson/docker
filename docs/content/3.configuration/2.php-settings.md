## Named variables

The frequently changed settings have their own variables with safe defaults. These are the ones you will set most often:

```bash
docker run --rm -d -p 8080:8080 \
  -e NGINX_PORT=8080 \
  -e PHP_MEMORY_LIMIT=512M \
  -e PHP_POST_MAX_SIZE=64M \
  -e PHP_UPLOAD_MAX_FILESIZE=64M \
  -e PHP_MAX_EXECUTION_TIME=120 \
  -e PHP_DATE_TIMEZONE=Europe/London \
  -e OPCACHE_ENABLE=1 \
  rollogi/php-nginx:8.4
```

The complete list, including security and OPcache settings, is in the [environment variable reference](/configuration/environment-variables#php).

::note
Nginx's `client_max_body_size` follows `PHP_POST_MAX_SIZE`, so raising the PHP upload limits is enough; you do not need to touch Nginx.
::

## Any php.ini setting

Any environment variable whose name starts with `php.` is appended to php.ini as `<setting> = <value>` after the templated settings, so it always wins.

```bash
-e php.max_input_vars=5000
-e php.realpath_cache_size=8M
-e php.session.gc_maxlifetime=7200
-e php.xdebug.max_nesting_level=512
```

This works in every image and applies equally to the CLI and to PHP-FPM, because both read the same rendered php.ini.

## Any PHP-FPM setting

Two more prefixes cover PHP-FPM:

| Prefix | Target | Example |
|--------|--------|---------|
| `fpm.pool.<setting>` | the `[www]` pool | `-e fpm.pool.pm.max_children=50` |
| `fpm.global.<setting>` | the `[global]` section | `-e fpm.global.log_level=debug` |

Bracketed keys work too. This is how you pin a setting for FPM only, so that it cannot be changed by `ini_set()`:

```bash
-e "fpm.pool.php_admin_value[memory_limit]=512M"
-e "fpm.pool.php_admin_flag[display_errors]=off"
```

::warning
Overrides are applied verbatim. `pm.max_children` must stay above `pm.max_spare_servers` (default 10) or FPM refuses to start, and the container logs the exact error.
::

Multi-line values are not supported.

## Docker Compose

Keys with dots are fine in Compose environment maps:

```yaml [compose.yaml]
services:
  app:
    image: rollogi/php-nginx:8.4
    environment:
      PHP_MEMORY_LIMIT: 256M
      php.date.timezone: Europe/London
      php.session.cookie_lifetime: "0"
      fpm.pool.pm.max_children: "40"
      fpm.pool.pm.start_servers: "8"
      fpm.pool.pm.min_spare_servers: "4"
      fpm.pool.pm.max_spare_servers: "12"
```

## Where the files end up

| File | Content |
|------|---------|
| `/run/php/php.ini` | Rendered from `php.ini.template`, then `php.*` overrides appended. |
| `/run/php/php-fpm.conf` | `[global]` with the error log, then `fpm.global.*` overrides, then the pool include. |
| `/run/php/php-fpm.d/www.conf` | Rendered pool, then `fpm.pool.*` overrides appended. |

The stock `/etc/php8x/` directory is never modified. See [Users and permissions](/configuration/users-and-permissions) for why.

## OPcache in production

```bash
-e OPCACHE_ENABLE=1
-e OPCACHE_VALIDATE_TIMESTAMPS=0     # code is immutable inside the image
-e OPCACHE_MEMORY_CONSUMPTION=256
-e OPCACHE_MAX_ACCELERATED_FILES=20000
```

From PHP 8.5, OPcache is compiled into PHP rather than installed as a separate package. The variables work the same way.

## Sending mail

There is no mail server in the images, but msmtp is included. Set `SMTP_HOST` and the entrypoint renders an msmtp configuration and points `sendmail_path` at it, so `mail()`, Laravel's `sendmail` mailer, Symfony's `sendmail://` transport and anything else that shells out to sendmail relays through your SMTP provider.

```yaml [compose.yaml]
environment:
  SMTP_HOST: smtp.postmarkapp.com
  SMTP_PORT: "587"
  SMTP_USER: ${POSTMARK_TOKEN}
  SMTP_PASSWORD: ${POSTMARK_TOKEN}
  SMTP_FROM: noreply@example.com
```

Defaults follow the port: 465 is implicit TLS, 25 and 1025 are plain, everything else uses STARTTLS; AUTH is on whenever `SMTP_USER` is set. Force any of them with `SMTP_TLS`, `SMTP_TLS_STARTTLS` and `SMTP_AUTH` (`on`/`off`). The rendered file lives at `/run/php/msmtprc` with mode 600 and is never logged. If you set `PHP_SENDMAIL_PATH` yourself it is left alone.

For local development, point `SMTP_HOST` at a [Mailpit](https://mailpit.axllent.org) container on port 1025 and read the mail in its web UI.
